# literatura.halyavka.net

Сайт з української літератури для 5–11 класів: короткі перекази, паспорти творів,
характеристики героїв, цитати, готові шкільні твори, біографії письменників,
список творів напам'ять і словник літературознавчих термінів.

## Швидкий старт

```bash
npm install
npm run dev      # http://localhost:4330
npm run build    # статична збірка у dist/
npm run preview
npm run check    # звіряє slug-и між каталогом програми і переліком НМТ
```

## Стек

Astro 5 (SSG) · TypeScript · Tailwind CSS 4 · Content Collections із Zod-схемою ·
`@astrojs/sitemap` · `@astrojs/rss` · MPA View Transitions. Ніякого JS-фреймворку:
інтерактив (тема, тест, пошук, копіювання) — це кілька десятків рядків ванільного скрипта.

## Структура

```
src/data/program.ts      каталог програми 5–11 клас (165 творів) — скелет сайту
src/data/terms.ts        словник літературознавчих термінів
src/data/nmt.ts          програма НМТ: 62 твори, герої, крилаті рядки
src/content/works/       розбори творів      → /tvory/<slug>/
src/content/essays/      шкільні твори       → /tvir-na-temu/<slug>/
src/content/authors/     біографії           → /pysmennyky/<slug>/
src/content.config.ts    Zod-схеми всіх трьох колекцій
```

Сторінки класів, розділ «напам'ять», пошук і sitemap будуються автоматично.

## Що вже працює

- Сторінка твору: паспорт, сюжет у трьох реченнях, стислий і докладний переказ,
  характеристики героїв із цитатами, художні засоби, план, теми творів, тест самоперевірки
- Сторінка шкільного твору: теза, план, цитати, кілька варіантів у розкривних блоках
  зі лічильником слів і кнопкою «скопіювати»
- Липкий зміст сторінки з підсвіткою активного розділу
- Світла й темна теми (перемикач + системна за замовчуванням), верстка під читання:
  серифний шрифт, 18–19 px, ширина колонки ~44rem
- Миттєвий пошук на клієнті (`/poshuk/`, індекс `/search.json`, без зовнішніх бібліотек);
  у видачу потрапляють і твори, до яких сторінки ще нема — вони ведуть на сторінку класу
- SEO: canonical, Open Graph, JSON-LD (WebSite + SearchAction, Article, Person), sitemap, RSS, robots.txt
- Розділ НМТ: формат тесту, усі 61 твір програми, «хто з якого твору», крилаті рядки
  і тренажер із питаннями, що генеруються щоразу нові (автор / жанр / герой / цитата)
- Друк: службові елементи ховаються (`.no-print`)
